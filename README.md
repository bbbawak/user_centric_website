# Healthcare Services Carrollton (Skeletal Website)

This project is an individual assignment website based on the team sitemap/prototype.

## Included Pages

- Home (`index.html`)
- Find a Provider (`find-provider.html`)
- Emergency (`emergency.html`)
- Resources (`resources.html`)
- FAQ (`faq.html`)
- Contact (`contact.html`)
- Accessibility (`accessibility.html`)
- Success page (`success.html`)

## Features Included

- Consistent header/footer on each page
- Navigation links across all required pages
- Accessibility settings panel (theme + font size + reset)
- Mobile nav toggle
- Contact form with HTML validation and redirect to success page
- Placeholder cards/sections aligned with prototype direction

## Quick Run

Open `index.html` in a browser, or serve with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
